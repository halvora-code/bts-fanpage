# bts-fanpage

What it is: this is a fan-page dedicated to the k-pop group bts. This includes things about the members, music, and interesting facts.

How I made it: I used a ton of HTML, CSS, and a little JavaScript. 

The challenges I faced: Trying to get a music player to play actual songs was a challenge and unfortunately I was not able to do it. Trying to line up text, images and buttons was a bit of a struggle. I added bubbles and learning how to do that was a little confusing with the different measurements. 

What I learned: I learned how to make buttons that lead to another window page. And I learned how to use CSS to make an animation with bubbles on the page. Its not perfect but its something new that I tried on this page and learned a lot from it.
